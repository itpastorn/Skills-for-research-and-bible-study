# Skills-for-research-and-bible-study

Claude/Cowork-skills för bibelforskning, jämförande studier av profetia/urskillning och relaterat undervisnings- och predikoförberedande arbete.

## Ingående skills

- **accordance-list** — Producerar kompakta, semikolon-separerade bibelreferenslistor i det format som Accordance och Logos kan parsa direkt vid copy-paste. Täcker GT, NT och apokryferna.
- **humaniora-forskningsoversikt** — Kartlägger forskningsläget inom humaniora (exegetik, systematisk teologi, kyrkohistoria, filosofi, historia, religionssociologi) via Consensus och Scholar Gateway.
- **prep-work-inside-file** — Skriver ut startinstruktioner för att arbeta direkt inuti Excel-filerna (tidsaxeln/personfilen) med Claude i Excel, till skillnad från vanlig Cowork-kontext.
- **prophetic-comparative-report** — Producerar jämförande rapporter mellan 2–5 verk (böcker, artiklar, uppsatser, egna utkast) om det profetiska och urskillning.
- **trellokort-nar-individ** — Skapar, uppdaterar och kommenterar kort i listan "Enskilda individer" på Trello-tavlan "NAR, Revival Alliance och trumpprofetism".

## Relaterat

- **sammanfatta-media** — ersätter den äldre `sammanfatta-youtube-video`-skillen. Nås endast via Claude Code och ingår inte i det här repot.

Skills är byggda för och används i Cowork/Claude av Lars Gunther (itpastorn).
